Завдання за варіантом 10

Умова: Реалізуйте систему обміну повідомленнями між двома процесами, де кожне повідомлення кодується у sigval.sival_int, і процес отримує повідомлення через sigqueue.

Пояснення: Код реалізує обмін повідомленнями між двома процесами через сигнали. У програмі P12-13.10.1.c використовується sigaction з прапором SA_SIGINFO, щоб обробляти сигнал SIGRTMIN та отримувати додаткову інформацію — PID відправника і значення, передане через sival_int. Обробник виводить цю інформацію на екран, а програма постійно чекає сигналів через pause().

Програма P12-13.10.2.c приймає PID цільового процесу та число-повідомлення як аргументи. Вона створює структуру sigval з цим числом і надсилає сигнал SIGRTMIN з даними через sigqueue. Таким чином, відбувається простий і ефективний обмін повідомленнями між процесами без використання сокетів чи файлів.
